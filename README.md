
## About 

This framework is designed to mentor students through visual and image-based learning sessions, making complex concepts easier to understand, engaging, and interactive. It focuses on combining visual aids, guided explanations, and hands-on practice to improve comprehension and retention.

## Setup Instructions
- Install Python3.17 (https://www.python.org/downloads/)
- Install pip using command: `python -m pip install --upgrade pip`
- To create virtual environment using command: `python -m pip install pipenv`
- To Activate virtual environment command : `pipenv shell`
- To install dependences use : `pipenv install`
